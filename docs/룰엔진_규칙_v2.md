## 1. 상수표 — 근거 포함

| 상수 | 값 | 근거 |
|---|---|---|
| `maxShiftPerDayMin` | **60** | 생체시계는 하루에 약 1시간 정도만 이동한다. <cite index="9-1">7일 연속 야간 근무를 해도 시계는 5~6시간만 이동하며, 완전 적응에 필요한 12시간의 절반에도 못 미친다.</cite> **"연속 근무하면 알아서 적응된다"는 통념이 틀렸다는 것이 우리 제품의 존재 근거** |
| `caffeineCutoffBeforeMin` | **528 (8.8h)** | <cite index="17-1">24개 연구 메타분석 결과, 총 수면시간 감소를 피하려면 커피(250mL당 107mg)는 취침 8.8시간 전까지 마셔야 한다.</cite> <cite index="12-1">카페인은 총 수면시간을 45분, 수면 효율을 7% 낮추고 입면 잠복기를 9분 늘린다.</cite> |
| `lightBlockBeforeMin` | **120** | 임상 권고: 퇴근길 및 주간 취침 1~2시간 전 선글라스 착용, 취침 전 광 노출 최소화 |
| `napShortMin` / `napLongMin` | **20 / 90** | <cite index="23-1">약 20분(깊은 수면 진입 전) 또는 약 90분(수면 주기 종료 시점)에 깨면 수면 관성이 덜하고 15~30분 내 회복된다.</cite> |
| **`napForbiddenRange`** | **30~80분 금지** | <cite index="22-1">20~90분 사이 낮잠은 깊은 수면 중 각성 확률이 높아 수면 관성을 유발하므로 피해야 한다.</cite> `napMinutes`는 20 또는 90 **두 값만** 반환할 것 |
| `napBeforeShiftMinMin` | **180** | <cite index="19-1">근무 시작 2~4시간 전 낮잠이 야간 근무자에게 가장 근거가 탄탄한 방식.</cite> 기상 후 각성 회복 시간 확보 |
| `defaultNeedSleepMin` | 420 (7h) | <cite index="5-1">상시 야간 근무자의 근무일 평균 수면은 약 6시간, 교대 근무자는 야간 근무 시 약 5.5시간으로 더 짧다.</cite> 7시간은 목표치이자 부채 계산 기준 |
| `windDownBeforeMin` | 60 | 임의값 유지 |
| `lightExposureAfterMin` | 30 | 임의값 유지 |
| `sessionMergeGapMin` | 30 | 구현 파라미터 |
| `phaseWindowDays` / `debtWindowDays` / `stdWindowDays` | 5 / 7 / 14 | 구현 파라미터 |

> **심사 대응(PM):** "왜 이 숫자인가" 질문이 오면 위 4개는 문헌으로 답할 수 있습니다. 특히 **카페인 8.8시간**은 대부분의 수면 앱이 "취침 6시간 전" 같은 관행값을 쓰는 것과 대비되는 지점이라 차별점으로 쓸 만합니다.

## 2. 4단계 계산

### ① 이상적 시각 역산

```
기준 근무 = tomorrowShift ?? todayShift

이상적_취침 = 기준근무.종료시각 + commuteMin + prepMin
이상적_기상 = 이상적_취침 + needSleepMin
```

양쪽 다 null(오프): 최근 5일 평균 취침 시각을 이상적 취침으로 사용.

### ② 현재 리듬 위상

```
세션 중간점 = (startAt + endAt) / 2
현재_위상 = 최근 5일 중간점의 순환 평균
```

> **순환 평균 필수.** 23:50과 00:10의 산술 평균은 12:00이지만 정답은 00:00입니다. 시각을 각도(분/1440 × 360°)로 바꿔 벡터 평균을 낸 뒤 되돌리세요. 여기서 틀리면 목표 시각이 12시간 어긋나는데 테스트로 잘 안 잡힙니다.

### ③ 단계적 이동 ← 제품의 핵심

```
이상적_중간점 = 이상적_취침 + needSleepMin/2
격차 = 이상적_중간점 − 현재_위상          (부호 있는 분, 순환 최단거리)

이동량 = clamp(격차, −60, +60)
오늘_목표_중간점 = 현재_위상 + 이동량
목표_취침 = 오늘_목표_중간점 − needSleepMin/2
목표_기상 = 목표_취침 + needSleepMin
```

**격차 계산 시 순환 최단거리를 쓸 것.** 현재 04:00, 목표 22:00이면 격차는 +18시간이 아니라 **−6시간**입니다. 항상 ±12시간 범위로 정규화하세요.

### ④ 행동 도출

```
caffeineCutoff : 목표_취침 − 528분
lightBlock     : 목표_취침 − 120분
windDown       : 목표_취침 − 60분
lightExposure  : 목표_기상 + 30분
```

## 3. 취침 / 낮잠 분기

```
todayShift.type ∈ {night, evening}
  AND 근무 시작까지 남은 시간 ≥ 180분
→ PlanType.nap

그 외 → PlanType.bedtime
```

### 낮잠 파라미터

```
napMinutes = sleepDebtMin ≥ 120 ? 90 : 20      // 이 두 값 외 금지
낮잠_시작  = 근무.시작시각 − 180분 − napMinutes
```

낮잠이 **근무 시작 3시간 전에 끝나도록** 배치합니다. 수면 관성이 남은 채로 출근하는 것을 막기 위함입니다.

### 낮잠일 때의 nudge

```
napStart       : 낮잠_시작
caffeineCutoff : 낮잠_시작 − 528분           // 낮잠 자체를 방해하지 않도록
lightExposure  : 낮잠_종료 + 15분
```

## 4. 나이트 근무 전용 규칙 (v2 신규)

**이 부분이 v1에 통째로 빠져 있었습니다.** 야간 근무자 리듬 관리의 핵심 개입이 여기 있습니다.

### 근거

<cite index="28-1">야간 근무 중 간헐적 고조도 광 노출, 퇴근길 최대한 어두운 선글라스, 규칙적인 이른 주간 암막 수면 — 이 조합이 완전한 리듬 적응에 권장된다.</cite>

<cite index="30-1">임상 권고 요약: 야간 근무 초반부터 근무 종료 2시간 전까지 밝은 빛 사용, 퇴근길과 주간 취침 1~2시간 전 선글라스 착용, 취침 전 광 노출 최소화, 침실 암막화.</cite>

### 규칙

```
todayShift.type == night 인 경우 추가:

brightLightAtWork  : 근무.시작시각 + 30분
                     (근무 종료 2시간 전까지 유효 — 문구로 안내)

sunglassesCommute  : 근무.종료시각 − 15분
                     (퇴근 직전 알림 → 건물 나서기 전 착용)
```

### 안전 단서 — 문구에 반드시 반영

<cite index="36-1">야간 근무 후 졸린 상태에서 짙은 선글라스를 쓰면 졸음이 늘어 졸음운전 위험이 커질 수 있다는 우려가 있다. 태워다 줄 사람이 있는 경우에만 짙은 선글라스를 쓰는 것이 가장 안전하다.</cite>

→ `sunglassesCommute` 문구에 **직접 운전 시 주의** 문구를 포함시킬 것. 이건 선택이 아니라 안전 요구사항입니다.

## 5. nudge 우선순위 — 최대 3개

발송 시각이 `now`보다 과거인 항목은 건너뜁니다. 위에서부터 채워 3개가 되면 중단.

**bedtime · night 근무**
```
1. sunglassesCommute      ← 리듬 이동 효과가 가장 큼
2. caffeineCutoff
3. lightBlock
4. brightLightAtWork
5. windDown
6. lightExposure
```

**bedtime · day/evening/off**
```
1. caffeineCutoff
2. lightBlock
3. windDown
4. lightExposure
```

**nap**
```
1. napStart
2. caffeineCutoff
3. lightExposure
```

## 7. 제품 메시지 (PM용)

발표에서 쓸 수 있는 근거 기반 문장 두 개입니다.

**① 통념 반박**
> "연속으로 야간 근무하면 몸이 적응한다"는 말은 사실이 아닙니다. 생체시계는 하루 약 1시간만 이동하기 때문에, 7일 연속 야간 근무를 해도 필요한 12시간 중 절반만 이동합니다. 그래서 저희는 적응을 기다리는 대신 **매일 이동 가능한 만큼만 목표를 옮기는 방식**을 택했습니다.

**② 기존 앱과의 차이**
> 대부분의 수면 앱은 카페인 마감을 취침 6시간 전으로 안내합니다. 메타분석 근거는 8.8시간입니다. 저희는 검증된 수치를 씁니다.

**③ 안전 고지 (필수)**
> 이 앱은 의학적 진단이나 치료를 제공하지 않습니다. 교대근무수면장애는 전문의 진단이 필요한 질환입니다.
