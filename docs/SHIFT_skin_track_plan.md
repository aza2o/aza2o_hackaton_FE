# SHIFT — 피부 트랙 기획서

> AAC 브랜드 트랙 제출용 · 슬라이드 작성 기반 문서
> 대상: 국내 3교대 병원 간호사 (D/E/N/Off)

---

## 0. 한 줄 정의

**크로노코스메틱은 지금까지 '몇 시'를 기준으로 만들어졌다. SHIFT는 '당신의 생체 시각'을 기준으로 만든다.**

기존 스킨케어의 AM/PM 구분은 벽시계를 전제로 한다. 나이트 근무 후 16시에 기상하는 간호사에게 이 전제는 무너진다. SHIFT는 서캐디언 엔진이 이미 산출하는 **생체 위상·광 노출·수면부채·확정 미래 로스터**를 그대로 재사용해 루틴 타이밍을 개인화한다. 추가 모델링 비용은 사실상 0이다.

---

## 1. 문제 정의

| 층위 | 내용 |
|---|---|
| 직군 특이 | 잦은 손위생·장갑 착용으로 인한 직업성 자극성 손습진 |
| 교대 특이 | 벽시계 기준 루틴이 실제 기상/취침과 어긋남 |
| 회복 지연 | 수면 부족 시 장벽 손상·UV 손상으로부터의 회복 지연 |
| 노출 오정렬 | 나이트 퇴근 시각(오전)이 UV 노출 시간대와 겹침 |

기존 뷰티 앱은 사용자의 **근무 스케줄을 모른다.** 따라서 위 네 가지 중 어느 것도 다룰 수 없다.

## 2. 설계 원칙 — 주장 가능 / 불가능 경계

이 트랙은 "야간근무자용 성분"으로 가면 근거가 없어 무너진다. **"무엇을 바르냐"가 아니라 "언제 바르냐"** 로 프레이밍한다.

| 주장한다 | 주장하지 않는다 |
|---|---|
| 피부 장벽 기능은 일주기 리듬을 가짐 | 교대 유형별 맞춤 성분 |
| 수면 제한 시 장벽 회복 지연 | 피부 상태 진단·개선 효과 |
| 간호사 직업성 손습진 위험 및 보습 빈도의 보호 효과 | 피부 나이 스코어링 |
| UV 노출 타이밍 최적화 | 특정 제품의 효능 |

## 3. 기능 스펙

### F1. 생체 하루 기준 루틴 재배치 — **핵심 / MVP 포함**

| 항목 | 내용 |
|---|---|
| 입력 | 엔진의 `plan_sleep()` 앵커 (권장 기상/취침 시각) |
| 산출 | AM 루틴 = 기상 시각, PM 루틴 = 주 수면 직전 |
| 추가 개발 | 앵커 값 연결만. 신규 모델링 없음 |
| 브랜드 매핑 | AAC의 AM/PM 제품 라인이 그대로 대응 |

**근거 논리**
- TEWL·피부 표면 pH·피부 온도에서 유의한 일주기 리듬 확인 (Yosipovitch 1998, n=16, 24h 2시간 간격)
- 저녁 TEWL 상승 = 장벽 기능 저하 = 국소 제제 투과성 증가 → "야간 보습·리페어"의 생리학적 근거
- 피크-트로프 차이 71~415%, 피부 온도로 설명되지 않음

**설계 주의**
- 각질층 수분량(SC hydration)은 리듬이 검출되지 않음 → **"수분 지수"를 시간 축 그래프로 표시하지 말 것**
- TEWL 리듬은 얼굴에서 일주기, 전완에서 12시간(ultradian) → 얼굴 루틴과 손 루틴을 같은 곡선으로 다루지 말 것
- acrophase는 연구 간 불일치 → 특정 시각을 못 박지 말고 **"주 수면 직전"처럼 상대 앵커로만** 표현

### F2. 퇴근길 자외선 알림 — **핵심 / MVP 포함**

두 트랙이 물리적으로 같은 행동으로 수렴하는 유일한 지점. 데모 설명력이 가장 높다.

| 항목 | 내용 |
|---|---|
| 트리거 | 로스터상 퇴근 시각 + 기상청 자외선지수 |
| 나이트 | 오전 퇴근 시 광 차단 → **위상 전진 방지 + UV 차단** 동시 달성 |
| 데이 | 오후 퇴근 시 잔존 UV 대응 |
| 임계값 | 자외선지수 단계 그대로 사용 (낮음 <3 / 보통 3–5 / 높음 6–7 / 매우높음 8–10 / 위험 11+) |

**근거 논리**
- 수면의 질이 나쁜 군은 노화 징후 증가 + 장벽 손상·UV 노출로부터의 회복 지연 (Baron / Estée Lauder 임상)
- → 나이트 근무자에게 UV는 일반인보다 **비용이 크다**. 회복이 느리기 때문.

**슬라이드 한 줄:** "선글라스 하나가 생체리듬과 피부를 동시에 지킵니다."

### F3. 손 케어 — **핵심 / MVP 포함 / 근거 최상** — ⚠️ 기능에서 제외 결정 (2026-08-18)

> 근거는 최상이었지만 제품 범위에서 빼기로 결정됨. 아래 내용은 결정 배경 기록용으로 남겨둔다.

행동 → 결과가 직결되는 유일한 항목이며, 국내 데이터가 정확히 존재한다.

**근거 (Lee SW et al., J Dermatol 2013 — 국내 종합병원 간호인력 n=525, 응답률 75%)**

| 지표 | 값 |
|---|---|
| 증상 기반 손습진 | **75.6%** |
| 자가보고 손습진 | 31.0% |
| 위험요인 | 젊은 연령, 아토피 병력, 손씻기 >20회/일, 장갑 착용 >5분 |
| 보호요인 | **보습제 >3–4회/일 사용 시 손습진 덜 빈번** |

보조 근거: 간호사 손습진 발생률 1,000인년당 16.9 (95% CI 11.2–22.7), 직업군 중 2위 (미용사 다음).

**기능 구현**
- 근무일 중 핸드크림 리마인더 (목표: 3–4회/일)
- 손위생 빈도 자가 입력 → 위험도 피드백
- 근무 시작/종료 시점에 앵커

**브랜드 연계 우위:** 재구매 주기가 짧아 제품 회전율이 높다. AAC 입장에서 가장 팔기 쉬운 기능.

### F4. 수면부채 연동 회복 모드 — **조건부 / 시간 여유 시**

| 항목 | 내용 |
|---|---|
| 입력 | Process S 누적값 |
| 동작 | 임계 초과 시 루틴 템플릿 전환: 유지형 → 진정·장벽형 (레티노이드·산 계열 스킵) |
| 프레이밍 | "피부가 상했다"(×) → **"장벽 회복이 느린 날엔 단순하게"**(○) |

효과 주장이 아니라 **자극 리스크 회피** 논리이므로 과잉주장이 발생하지 않는다.

**근거**
- 40대 한국 여성 32명, 8h×6일 → 4h×6일 조건에서 장벽 회복 포함 다항목 측정 (스마트워치로 수면 모니터링) — **설계가 SHIFT와 거의 동일**
- 30–55세 여성 24명, 3h×2일 수면제한 → 수분도·TEWL·탄력·pH·산화(MDA) 변화, 사진상 밝기·채도 저하 및 다크서클 증가

**⚠️ 반대 근거 (선제 대응 필수)**
국내 최근 연구는 *수면 부족 단독으로 장벽이 손상되었음을 확인하지 못했다*고 명시한다. 심사 시 파고들 수 있는 지점.
→ 대응: 인정하고 넘어간다. **"그래서 우리는 개선 효과가 아니라 자극 회피를 권합니다."**

## 4. AAC 브랜드 트랙 킬러 포인트

서캐디언 엔진과 **정확히 같은 논리**를 피부에 적용한다 — 확정된 미래 로스터를 입력으로 쓴다.

> **"다음 2주에 나이트가 5개 잡혀 있습니다. 그 전에 준비하세요."**

- 사후 추천(피부 나빠짐 → 제품)이 아니라 **선제 추천**
- 스케줄을 아는 뷰티 앱은 존재하지 않음
- 서캐디언 트랙의 차별점과 문장 구조가 동일 → 발표에서 **한 번만 설명하면 두 트랙이 함께 선다**

**제품 매핑 슬롯** (AAC 라인업 확정 후 채움)

| 트리거 | 제품 슬롯 |
|---|---|
| 생체 AM 루틴 | 주간 보호 / 선케어 |
| 생체 PM 루틴 | 야간 보습·리페어 |
| 퇴근 UV 알림 | 선케어 |
| 근무 중 손 케어 | 핸드케어 (고회전) |
| 회복 모드 발동 | 진정·장벽 |
| 로스터 사전 알림 | 번들 / 정기 배송 |

## 7. 슬라이드 구성안 (6장)

| # | 메시지 | 비주얼 | 근거 |
|---|---|---|---|
| 1 | 벽시계 AM/PM은 교대 근무자에게 작동하지 않는다 | 일반인 vs 나이트 근무자 24시간 타임라인 대비 | — |
| 2 | 피부 장벽은 실제로 리듬을 갖는다 | TEWL 24시간 코사이너 곡선 | Yosipovitch 1998 |
| 3 | 그래서 루틴을 생체 시각으로 재배치한다 | 로스터 → 앵커 → 루틴 시각 플로우 | F1 |
| 4 | 하나의 행동이 두 트랙을 동시에 만족시킨다 | 나이트 퇴근 시각 × UV지수 × 위상 전진 방지 겹침도 | F2 |
| 5 | 간호사의 손: 근거가 가장 단단한 지점 | 75.6% / 보습 3–4회 보호효과 대비 막대 | Lee 2013 |
| 6 | 우리는 미래를 안다 — 선제 추천 | 2주 로스터 위에 사전 알림 마커 | AAC 연계 |

## 8. 예상 질문 & 대응

**Q. 교대 유형별로 피부가 다르다는 근거가 있나?**
A. 없습니다. 그래서 성분을 차등하지 않고 **타이밍만** 개인화합니다. 근거가 있는 것만 주장합니다.

**Q. 수면 부족이 피부를 나쁘게 한다는 게 확실한가?**
A. 회복 지연은 여러 연구에서 일관되지만, 수면 부족 단독의 장벽 손상은 국내 최근 연구에서 확인되지 않았습니다. 그래서 개선 효과가 아니라 **자극 회피**를 권합니다.

**Q. 화장품법 위반 소지는?**
A. 진단·효능 표현을 전부 배제하고 루틴 타이밍 제안으로만 구성했습니다. 식약처 위반 사례에 명시된 '피부 나이' 지표는 의도적으로 제외했습니다.

**Q. 기존 크로노코스메틱과 뭐가 다른가?**
A. 기존은 벽시계 기준입니다. 우리는 생체 시각 기준이며, 그 계산에 **확정된 미래 근무표**를 씁니다.

## 9. 미해결 갭 (내부용)

- 교대 유형(D/E/N)별 피부 차이 직접 연구 **없음**. 대안: Frontiers in Immunology 2022 리뷰가 교대근무의 행동·신경내분비·체온조절·피부 생리·면역 변화를 **4시간 간격 표**로 정리 → 루틴 템플릿의 시간 격자 골격으로 사용 가능. 현 시점 가장 실용적인 단일 문헌.
- TEWL acrophase 연구 간 불일치 → 절대 시각 표기 금지
- 모든 근거가 정상 주간형 대상. 야간근무자의 피부 말초 시계 이동 폭은 미측정 영역
- AAC 라인업 확정 전까지 §4 제품 매핑 슬롯 공백
